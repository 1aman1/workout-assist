# Dropped Features

This file tracks ideas that were intentionally removed so they can be reconsidered later.

## 2026-07-07: Workout day cycle swipe navigation

- Dropped feature:
  - Left/right swipe on workout.day header to move to previous/next cycle occurrence of the same workout.
  - Contextual Today button for returning to current cycle view.
- Why it was dropped:
  - Added interaction complexity on workout.day.
  - Risk of accidental navigation while interacting with the header area.
- Revisit trigger:
  - Reconsider only if users explicitly ask for cycle browsing again.
- Prior versions:
  - Introduced in v1.77.
  - Extended with Today-return in v1.78.
  - Removed in v1.79.
